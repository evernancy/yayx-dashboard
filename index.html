模板 1（库存明细，逐 SKU）：每行 = 一个 SKU 在某天的库存快照，含 时间 / 商品名称 / SKU / 品牌 / 一级~三级类目 / 店铺名称 / 供应商 / 全国采购价 / 库存件数 / 现货库存 / 可用库存 / 近7~90日出库商品件数 / 月至今出库商品件数 / 预计可售天数 / 无货pv / PV现货率 等全量列（列名自动识别，缺列留空）。同一「时间 + SKU」重复录入即覆盖更新。
库存周转模块仅展示以下 13 个指标（其余指标不再展示）：库存金额、库存周转（天）、近7天销售（金额）、近14天销售（金额）、日均销售（金额）、60-90天长库龄预警金额（及基调/复调）、90天以上长库龄金额（及基调/复调）、PV现货率、实库现货率。
库存金额已接计算逻辑：库存金额 = Σ(库存明细:现货库存 × 全国采购价) + Σ(采购单:采购金额，按「订购时间」同日归并)；其余 12 项暂按读列展示（缺列留空）。

数据输入区

三种方式任选：① 从 Excel 复制后直接粘贴（含表头）② 粘贴 CSV 文本 ③ 上传 .csv / .xlsx 文件。所有上传（无论全量还是增量）均按「增量更新」处理：新数据与已有数据按业务键合并（同键更新、新键追加），重复的数据自动忽略，历史数据保留不清空；如需清空某一数据集请用各区「清除历史」按钮。修改后图表自动实时更新，并自动保存在本机浏览器中。

2.2 · 浮码数据

浮码数据与库存周转数据相互独立，本框单独录入、单独存储。表头：时间 / SKU / 浮码（无需录入出库件数）。「全国昨日出库商品件数」自动取自「库存周转数据」明细中的「昨日出库商品件数」列，按时间 + SKU 匹配；公式为 Σ（浮码 × 昨日出库商品件数）÷ 1.129，用于计算 POS 实际数据。库存明细缺该 SKU/日期的昨日出库时该项留空（不计入 POS）。同一「时间 + SKU」重复录入即覆盖更新。
